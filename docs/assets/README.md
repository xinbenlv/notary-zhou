# Product previews

`global-guides-mobile.png` shows the Chinese topic hub from a local production build. `global-guides-desktop.png` is historical evidence of the superseded English release and is not used in the product README or published as a website page. Images contain public guide content only and exceed the text-file size limit because they are visual verification artifacts.

`notary-lookup-before.png` and `notary-lookup-after.png` compare the English
lookup page at 390px using local builds. The preview has no listing API backend;
its unavailable-status message is expected. The new links render without the API
or JavaScript. Only public record identifiers and public interface text appear.
